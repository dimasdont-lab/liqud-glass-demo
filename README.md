# Voice Finance Free v0.6

Повністю безплатний тестовий веб-застосунок без платних AI API.

## Швидке введення
- Голосовий ввід тимчасово вимкнено через нестабільний повторний запуск Safari SpeechRecognition та слабку точність локальних моделей на iPhone.
- Центральний плюс відкриває компактне текстове поле й клавіатуру.
- Текст локально розбирається як звичайна операція або борг; жодних API-запитів немає.

## Збережений експериментальний voice fallback
- Мікрофон записується через `MediaRecorder`.
- Аудіо декодується локально у браузері та приводиться до mono 16 kHz.
- Транскрипція працює локально через open-source Whisper у `whisper-worker.js` / Transformers.js.
- На iPhone/iPad основним є безкоштовне вбудоване SpeechRecognition Safari з `uk-UA`: воно значно краще за Tiny розуміє живу українську. Це не платний API, але обробку контролює Safari/Apple, а не застосунок.
- Через iOS-баг повторного запуску Safari SpeechRecognition перший запис використовує Safari, а наступні записи без перезавантаження автоматично переходять на MediaRecorder + локальний Whisper. На Safari 26/WebGPU спочатку використовується точніший multilingual Whisper Base.
- Якщо браузерне розпізнавання недоступне, використовується multilingual Whisper Tiny q8 через однопотоковий WASM. `whisper-base` не вмикається автоматично на iPhone через підтверджені падіння вкладки iOS Safari.
- На сумісних desktop-браузерах спочатку пробується Whisper Base q4 через WebGPU, потім Tiny q8 / WASM.
- Мову жорстко не фіксує: розраховано на українську + польську + англійську в одній фразі.
- Перший запуск завантажує модель з Hugging Face. Це безкоштовно; далі браузер використовує кеш.
- Аудіо ніколи не відправляється в OpenAI або інший платний API. У Safari-режимі діють системні правила розпізнавання Apple; у Whisper fallback усе виконується локально.
- Запис автоматично зупиняється через 30 секунд, а зависла транскрипція скидається через 4 хвилини.
- Закриття voice sheet або помилка завжди зупиняє всі microphone tracks; застарілі async-відповіді ігноруються.

### Реальне обмеження iPhone

Повністю локальна модель на iPhone має нижчу точність і більшу затримку, ніж системне диктування. Тому Safari SpeechRecognition тепер має пріоритет, а Tiny лишається аварійним локальним fallback. Текстовий парсер і ручне додавання не залежать від голосового рушія.

Перший запуск потребує мережі для завантаження open-source моделі. Safari кешує модель для наступних запусків, але може видалити кеш при нестачі місця.

## Парсер
Локально розбирає суму, валюту, тип операції, клієнта, категорію і відомих мерчантів. Є fuzzy-розпізнавання для варіантів на кшталт `Biedronka / бєдронка / бедронка`.

Перевірені текстові приклади:
- `200 злотих Biedronka` -> Витрата / 200 PLN / Продукти
- `мінус 45 злотих Uber` -> Витрата / 45 PLN / Транспорт
- `плюс 3000 злотих від Johnny за зйомку` -> Дохід / 3000 PLN / Johnny / Бізнес
- `Johnny заплатив мені 2000 за монтаж` -> Дохід / 2000 PLN / Johnny / Бізнес
- `50 євро hotel Booking` -> Витрата / 50 EUR / Подорожі
- `dwieście złotych Biedronka` -> Витрата / 200 PLN / Продукти
- `two hundred PLN Uber` -> Витрата / 200 PLN / Транспорт

## Борги

Екран «Борги» має представлення «Я винен», «Мені винні» та «Термінові». У кожному є розгортані розділи «Не оплачено» й «Оплачено». Записи можна додавати, редагувати та видаляти; підтримуються PLN, EUR, USD і GBP. Текстові фрази на кшталт `я винен Олегу 500` або `Марек винен мені 300 PLN` автоматично потрапляють у правильний список.

## Рахунки та баланс

- Верхній тікер показує всі рахунки, короткий графік і зміну балансу. Його швидкість розраховується так, щоб ширина екрана проходила за 3 секунди.
- На головній є Monobank, PKO, Revolut, Erste, готівка та ручні рахунки. Початкові значення явно є демонстраційними, а не реальним банківським підключенням.
- Графік загального балансу відкриває детальний аналіз за `7D / 1M / 3M / YTD / 1Y / ALL` з дотиком по точках і розбивкою по рахунках.
- Історія зберігається локально у вигляді `BalanceSnapshot`, разом із балансами окремих рахунків.

## Безпечні банківські підключення

Статичний GitHub Pages фронтенд не зберігає токени, OAuth secrets, PIN, паролі чи SMS-коди. У `worker/` додано безплатний Cloudflare Worker + D1 каркас. Детальні правила й налаштування описані у `BANKING_INTEGRATION.md`.

Особистий токен Monobank надсилається тільки в налаштований backend, там перевіряється і зберігається зашифрованим AES-GCM. Якщо backend URL не налаштований, поле очищається, а токен не потрапляє в `localStorage`. PKO/Revolut/Erste передбачені як серверні OAuth-конектори; небезпечної browser-only імітації немає.

## Хостинг
Це повністю статичний сайт. Його можна безкоштовно розмістити на GitHub Pages або іншому безкоштовному статичному HTTPS-хостингу.

GitHub Actions workflow у `.github/workflows/pages.yml` публікує `main` у GitHub Pages без build-кроку та без платних сервісів.
